Lumarie Calendar

Lumarie Calendar is a privately operated application for a household wall display. It reads selected calendars, combines their events and produces a calendar image on a local computer for the household display.

The Google connection uses read-only access to list calendars and retrieve events. It does not create, edit or delete Google Calendar events or change sharing permissions. The local controls select which calendars appear. Optional AI features shorten event labels and compare possible duplicates; their data use is explained in the privacy policy.

This site provides app information only. It contains no private calendar view, public sign-up or Google sign-in flow. The application and calendar data are operated separately on the household network.
